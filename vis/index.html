使用方式

06

课堂讲解

打开任一章节后，左侧选小节，顶部切换「讲解 / 代码 / 演示」三个 Tab，一边讲解、一边实时运行。

学生自学

按章节顺序过完所有关键点，每个关键点配有「为什么这么写」与「有什么坑」两段说明。

教师备课时

每个章节有独立的 demo/ 子目录，可单独运行、单独修改、单独打包给学生。

局域网使用

若公网不通，可在本机运行 python -m http.server 8080，学生连同一 WiFi 即可访问。

关于本课程

07

理论来源

陈为《可视化导论》、Mackinlay 1986、Stevens 1946、Cleveland 1984、Bostock D3 官方文档、Card 1999 数据流模型。

设计原则

案例为中心，而非理论为中心。每个知识点都嵌入到实践案例里，配关键点解释与可运行演示。

技术栈

零依赖：纯 HTML + CSS + ES modules + D3.js v7（CDN）。一条命令 python -m http.server 启动，无需 npm。

数据集

新生数据 CSV 与 Crime 数据等已打包进 data/ 目录，浏览器 fetch 加载，离线可用。
