地震相智能分类 · 示范案例包
================================

这是什么
--------
一个「地震相智能分类」的纯前端教学案例：用合成地震切片演示切片图像分类、
半监督扩展（稀疏井标签 → 伪标签）与相带概率体输出。所有计算都在浏览器里
实时完成，不依赖任何后端。

怎么用
------
1. 直接双击打开 demo/index.html（整页模式，样式/脚本自动内联）。
2. 页面上三段实验 + 一段可选的「算法解剖」动画，控件都能拖。

文件清单
--------
case.json        站点元数据（专业背景 + 案例流程 + 示范引用）
demo/index.html  整页示范（算法解剖 + 3 个实验）
demo/demo.js     模型层 + 浏览器接线（切片分类/半监督/概率体）
demo/flow.js     算法解剖六阶段动画
demo/aflow.*     算法解剖引擎（公共）
demo/aiq.*       问答/评价组件（公共）
demo/demo.css    页面样式
_validate.js     模型层单测（node _validate.js）

示范内容
--------
屏 1  切片分类：合成相带切片 + 卷积分类，拖「分类权重」看判别
屏 2  半监督扩展：井标签 → 高置信伪标签 → 全数据体覆盖
屏 3  相带概率体：邻域一致化 → 连续相带图 + 复核
算法解剖：切块 → 井标签 → 分类 → 半监督 → 概率体 → 复核

想改成你自己的案例
------------------
改 demo/demo.js 的 Model 层（genSliceGrid / classifySlice / semiExpand /
faciesProb），页面与动画会自动跟随新数据。需要换真实切片或井数据时，把
genSliceGrid 换成读取真实地震切片与井标签的加载逻辑即可。
