电潜泵故障预警 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：采油 · 电潜泵故障预警 · 电流卡片退化预警，
用时序异常检测 + 退化趋势建模方法解决坏了才修，±10A 绝对值报警抓不住结垢这类慢退化。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（esp-fault-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

示范内容
--------
【算法解剖】示范页最上方的核心板块：把「电流卡片 → 故障预警」拆成 6 步自动放慢播放——
  · 电流卡片：720 分钟时序，标出停机检修段与清洗后的连续曲线；
  · 滑窗特征：窗口在时序上一格格右移，每停一格重算 μ / k / σ；
  · 两种检测器：绝对值检测与趋势检测并排放在同一段数据上，
    看得见「慢退化为什么会被漏掉」；
  · 退化拟合：最近 20 天的最小二乘直线与外推段；
  · RUL 外推：直线 ∩ 报警阈值 = 该检泵日，剩余天数；
  · 分级决策：24 口井的二维特征空间与四级边界、提前量分布。
  每一步跑的都是与实验 1—3 同一份真代码。

实验 1 · 电流卡片 + 异常检测
  切换故障类型（气锁/结垢/电机过热/停泵）、调噪声，看电流时序形态差异，
  再对比两种检测器——为什么「只看绝对值」会漏掉缓慢爬升。

实验 2 · 退化趋势与剩余寿命
  用最近一段数据拟合退化斜率，外推到「跌破报警阈值」那一天，
  中间的天数就是剩余寿命 RUL；可拖拟合窗口看估计怎么变化。

实验 3 · 分层预警
  24 口井二维特征 + 四级分级 + 混淆矩阵 + 提前量分布，
  拖灵敏度在「检出更多」与「误报更少」之间取平衡。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
