露头裂缝自动统计 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：地质勘察 · 露头裂缝自动统计，
用实例分割 + 骨架化 + 摄影测量标定 + 产状反算，
解决人工逐条量半天/露头、有选择偏差、不同人量走向差 10° 的问题。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（g4-outcrop-fracture-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

示范内容
--------
【算法解剖】示范页最上方的核心板块：把「露头照片 → 裂缝统计」拆成 6 步自动放慢播放——
  · 数据采集：多角度照片 + 无人机点云 + 标定板；
  · 实例分割：每条裂缝一个掩膜；
  · 骨架化：提炼裂缝中心线、量长度；
  · 摄影测量标定：像素 → 真实方位与尺度；
  · 产状反算：走向玫瑰图 + 线密度；
  · 实测验证：罗盘实测校准走向误差。
  每一步跑的都是与实验 1—3 同一份真代码。

实验 1 · 裂缝实例分割
  拖分割阈值，看裂缝怎么从「全检出」到「漏掉小裂缝」——
  阈值高保守、低粘连。

实验 2 · 骨架化 + 线密度
  拖最小长度过滤掉过短裂缝，看骨架怎么量出
  每条裂缝的长度与走向。

实验 3 · 产状反算 + 验证
  拖标定误差看走向玫瑰图怎么失真，拖验证比例
  看实测如何校准走向误差到 ≤3°。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
