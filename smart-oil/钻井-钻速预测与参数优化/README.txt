钻速预测与参数优化 · 示范案例包
================================

这是什么
--------
一个「钻速预测与参数优化」的纯前端教学案例：用合成的钻时序列演示钻速
时序回归、贝叶斯优化找最优参数，以及保守 vs 最优参数的钻速对比。
所有计算都在浏览器里实时完成，不依赖任何后端。

怎么用
------
1. 直接双击打开 demo/index.html（整页模式，样式/脚本自动内联）。
2. 页面上三段实验 + 一段可选的「算法解剖」动画，控件都能拖。

文件清单
--------
case.json        站点元数据（专业背景 + 案例流程 + 示范引用）
demo/index.html  整页示范（算法解剖 + 3 个实验）
demo/demo.js     模型层 + 浏览器接线（预测/优化/对比）
demo/flow.js     算法解剖六阶段动画
demo/aflow.*     算法解剖引擎（公共）
demo/aiq.*       问答/评价组件（公共）
demo/demo.css    页面样式
_validate.js     模型层单测（node _validate.js）

示范内容
--------
屏 1  钻速时序预测：随钻参数 → 钻速，拖回归权重/切参数
屏 2  贝叶斯优化：参数空间热力图 + 优化轨迹找最优
屏 3  保守 vs 最优参数：钻速提升 + 风险可控
算法解剖：接入 → 特征 → 预测 → 优化 → 对比 → 部署

想改成你自己的案例
------------------
改 demo/demo.js 的 Model 层（genDrill / ropPredict / ropModel /
bayesOptimize / conservativeParams），页面与动画会自动跟随新数据。
需要换真实钻时数据时，把 genDrill 换成读取真实随钻参数的加载逻辑即可。
