油气地球化学异常识别 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：地质勘察 · 油气地球化学异常识别，
用多指标联合检测（鲁棒协同度）+ 空间聚类 + 地统计插值，
解决单指标阈值被地表污染点骗、逐点判读圈靶慢的问题。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（g2-geochem-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

示范内容
--------
【算法解剖】示范页最上方的核心板块：把「采样点 → 靶区概率图」拆成 6 步自动放慢播放——
  · 采样整理：坐标 + 多指标，剔缺测、标准化；
  · 异常检测：鲁棒 z-score 协同度 → 每点异常分数；
  · 分数分布：单指标 vs 多指标联合对比；
  · 空间聚类：DBSCAN 把邻近高异常点聚成靶区；
  · 概率图：IDW 插值成连续概率场 + 高/中/低分层；
  · 验证回写：与已知靶区重合度 → 人工复核。
  每一步跑的都是与实验 1—3 同一份真代码。

实验 1 · 多指标异常检测
  单指标 vs 多指标命中率对比，拖异常阈值与背景噪声——
  为什么单指标被污染点骗、多指标协同度只认「多项一起偏高」。

实验 2 · 空间聚类成靶区
  拖邻域半径 eps / 最小点数，看异常点怎么聚成靶区、
  孤立假异常怎么被剔除。

实验 3 · 靶区概率图
  调圈定阈值 / 插值幂 / 高潜力线，看离散点怎么平滑成
  概率图、与已知靶区的重合度多少。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
