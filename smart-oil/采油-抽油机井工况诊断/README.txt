抽油机井工况诊断 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：采油 · 抽油机井工况诊断 · 示功图智能判读，
用计算机视觉（卷积神经网络 + 原型网络）方法解决老师傅逐幅判读示功图，标准不一、复合故障易判错。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（pumping-diag-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

文件清单
--------
  case.json          清单：元信息 + 专业背景 + 案例流程
                      专业背景每段配一张「概念图」，把石油机理讲清楚
                      案例流程每一步配一张示意图，把这一步在做什么画出来
  demo/index.html    示范页（整页模式，沙箱 iframe 中运行）
  demo/demo.css      示范页样式

  demo/aflow.js      算法解剖引擎（阶段轨道 / 播放控制 / 实时读数）
  demo/aflow.css    算法解剖样式
  demo/flow.js       CNN 前向全流程的 7 阶段逐帧动画（栅格化→卷积→ReLU→特征→原型→双闸）
  README.txt         本文件

示范内容
--------
【算法解剖】示范页最上方的核心板块：把 CNN 的前向传播拆成 7 步自动放慢播放——
  · 栅格化：曲线沿 4000 步被写进 32×32 格子，像素逐个点亮；
  · 卷积：5×5 核在图上滑窗，25 项乘法逐条列出、滚动显示、累加器实时可见；
  · ReLU：负响应被压平的直方图（为什么不能省这层非线性）；
  · 四象限均值：32×32 → 32 维特征向量怎么拼出来；
  · 原型匹配：到 30 个原型的距离与 softmax 概率；
  · 双闸判定：置信度 ≥0.75 且距离 ≤τ 才采纳，否则转人工。
  每一步跑的都是与屏 2 同一份真代码，改参数立即重算。

屏 1 · 生成一张示功图
  一台「示功图生成器」：抽油机与井下泵联动动画，四个参数滑杆
  （充满系数 / 含气 / 漏失 / 冲次）实时改变示功图形状；预设按钮一键切换
  正常、供液不足、气锁、泵漏失、杆断脱、复合疑难六种工况。

屏 2 · 分类器怎么读图
  完整前向过程可视化：曲线 → 32×32 灰度图 → 8 个 5×5 卷积核
  → ReLU 响应图 → 32 维特征 → 原型匹配 + softmax 概率 + 分布外距离。
  每通道四行怎么看：响应图（深靛=无响应，青=中，琥珀=强）、
  能量条（越过中点=比常态活跃）、5×5 卷积核（绿=正权，棕=负权，训练后锁死）、
  通道名。零响应会画斜纹并标注「无响应」。

屏 3 · 区块级批量判读
  24 口井一轮：21 口纯工况直接采纳且全部判对，3 口复合疑难被距离阈值
  拦下转人工，复核占比 12.5%。点任意井卡可把它的参数载入屏 1 细查，
  「重新模拟一轮」可换一批井。混淆矩阵按「真实工况 × 模型判定」逐格实时统计，
  点格子直接跳到对应井；拖动 τ 实时看「省人力」与「少误判」的权衡曲线。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
