智能注水调配 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：采油 · 智能注水调配 · 连通建模 + 代理模型 + 约束优化，
用信号处理（互相关/去趋势）+ 核回归代理模型 + 遗传算法方法解决季度人工试调，一次调整影响全区，误判代价高。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（waterflood-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

文件清单
--------
  case.json          清单：元信息 + 专业背景 + 案例流程
                      专业背景每段配一张「概念图」，把石油机理讲清楚
                      案例流程每一步配一张示意图，把这一步在做什么画出来
  demo/index.html    示范页（整页模式，沙箱 iframe 中运行）
  demo/demo.css      示范页样式

  demo/aflow.js      算法解剖引擎（阶段轨道 / 播放控制 / 实时读数）
  demo/aflow.css    算法解剖样式
  demo/flow.js       井组数据→最优配注的 6 阶段逐帧动画（滞后搜索→去趋势→代理→GA）

示范内容
--------
【算法解剖】示范页最上方的核心板块：把「井组数据 → 最优配注方案」拆成 6 步
自动放慢播放——
  · 注入信号：梯形脉冲是连通估计的有效激励——多注一次水，看哪口井几天后动；
  · 滞后搜索：τ 从 0 扫到 20，相关系数在真值滞后处鼓起一个包；
  · 差分去趋势：固定带共同漂移做对照，看最弱连通的 P4 被误判成强连通；
  · 分层物理：设定配注与实际吸水并排画，说明渗透率如何「劫持」配注；
  · 代理模型：100 组样本训练高斯核回归，LOOCV 与独立验证集给精度；
  · 遗传算法：逐代收敛、编码内嵌约束、放回真模拟器复核。
  每一步跑的都是与实验 1—3 同一份真代码。

实验 1 · 注采连通分析
  拖噪声、开关「共同漂移」与「差分去趋势」，看算法怎么从两条曲线估出
  连通强度、滞后多久；关掉去趋势就能看到假连通怎么出现。

实验 2 · 层间矛盾
  拖四层配注，对照「理想配注 / 你的设定 / 实际吸水」——
  差距就是数据模型要补的盲区。

实验 3 · 代理模型 + 约束优化
  100 组样本训练代理模型（毫秒评估），遗传算法在约束内搜解，
  再放回真模拟器复核；拖控水权重看解沿帕累托前沿移动。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
