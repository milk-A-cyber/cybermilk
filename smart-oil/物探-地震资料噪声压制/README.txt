地震资料噪声压制 · 示范案例包
================================

这是什么
--------
一个「地震资料噪声压制」的纯前端教学案例：用合成的含噪地震剖面演示
去噪网络（含噪 → 干净）、自监督训练与域适配、以及保真约束与残留验收。
所有计算都在浏览器里实时完成，不依赖任何后端。

怎么用
------
1. 直接双击打开 demo/index.html（整页模式，样式/脚本自动内联）。
2. 页面上三段实验 + 一段可选的「算法解剖」动画，控件都能拖。

文件清单
--------
case.json        站点元数据（专业背景 + 案例流程 + 示范引用）
demo/index.html  整页示范（算法解剖 + 3 个实验）
demo/demo.js     模型层 + 浏览器接线（去噪/自监督/保真）
demo/flow.js     算法解剖六阶段动画
demo/aflow.*     算法解剖引擎（公共）
demo/aiq.*       问答/评价组件（公共）
demo/demo.css    页面样式
_validate.js     模型层单测（node _validate.js）

示范内容
--------
屏 1  去噪网络：含噪剖面 → 干净剖面，切噪声类型/强度/去噪强度
屏 2  自监督与域适配：裸平滑 vs 自监督去噪对比
屏 3  保真与残留验收：信噪比提升 × 保真度 + 分区复核
算法解剖：接入 → 合成对 → 去噪 → 自监督 → 保真 → 成像

想改成你自己的案例
------------------
改 demo/demo.js 的 Model 层（genSection / addNoise / denoise /
selfSup / preserveEval），页面与动画会自动跟随新数据。需要换真实含噪
炮集时，把 genSection + addNoise 换成读取真实含噪道集的加载逻辑即可。
