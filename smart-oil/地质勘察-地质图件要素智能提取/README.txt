地质图件要素智能提取 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：地质勘察 · 地质图件要素智能提取，
用目标检测 + OCR + 版面分析 + 矢量追踪，
解决人工描图 1—2 人日/幅、图例体系不统一、外包质量参差的问题。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（g3-map-extract-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

示范内容
--------
【算法解剖】示范页最上方的核心板块：把「扫描图件 → 矢量图层」拆成 6 步自动放慢播放——
  · 扫描接入：统一分辨率、分块切图、标注准备；
  · 目标检测：定位图例符号 / 断层线 / 钻孔柱状图；
  · OCR 识别：把注记从像素读成文本；
  · 版面分析：理清图区 / 图例区 / 注记区；
  · 矢量追踪：沿断层线像素重建折线矢量；
  · 图例映射：符号 → 岩性语义 + 抽检把关。
  每一步跑的都是与实验 1—3 同一份真代码。

实验 1 · 目标检测
  拖检测阈值，看符号 / 断层 / 柱状图怎么随「保守 vs 激进」变化——
  阈值高漏检多、误检少，低则相反。

实验 2 · OCR 识别
  拖错误率模拟扫描件清晰度，看注记文本识别准确率怎么变化——
  手写、模糊件 OCR 易错，错误会污染属性表。

实验 3 · 版面分析 + 矢量追踪
  调连接 gap，看色块（区块）与曲线（断层矢量）怎么生成——
  图怎么被拆成区、断线怎么跨缺口连接成矢量。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
