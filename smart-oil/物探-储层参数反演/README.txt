储层参数反演 · 示范案例包
================================

这是什么
--------
一个「储层参数反演」的纯前端教学案例：用合成的井震数据演示深度回归
（多属性 → 孔隙度）、多属性融合与物理约束校正。所有计算都在浏览器里
实时完成，不依赖任何后端。

怎么用
------
1. 直接双击打开 demo/index.html（整页模式，样式/脚本自动内联）。
2. 页面上三段实验 + 一段可选的「算法解剖」动画，控件都能拖。

文件清单
--------
case.json        站点元数据（专业背景 + 案例流程 + 示范引用）
demo/index.html  整页示范（算法解剖 + 3 个实验）
demo/demo.js     模型层 + 浏览器接线（回归/融合/约束）
demo/flow.js     算法解剖六阶段动画
demo/aflow.*     算法解剖引擎（公共）
demo/aiq.*       问答/评价组件（公共）
demo/demo.css    页面样式
_validate.js     模型层单测（node _validate.js）

示范内容
--------
屏 1  深度回归：井孔隙度真值 + 网络预测，拖「回归权重」看拟合
屏 2  多属性融合：振幅/频率/阻抗加权 → 孔隙度
屏 3  物理约束：范围约束前后孔隙度场对比 + 越界校正
算法解剖：对齐 → 井标签 → 回归 → 融合 → 约束 → 复核

想改成你自己的案例
------------------
改 demo/demo.js 的 Model 层（genWell / deepRegress / multiFuse /
physConstrain），页面与动画会自动跟随新数据。需要换真实井震数据时，
把 genWell 换成读取真实测井与地震属性的加载逻辑即可。
