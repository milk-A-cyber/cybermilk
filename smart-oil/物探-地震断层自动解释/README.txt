地震断层自动解释 · 示范案例包
================================

这是什么
--------
一个「三维断层自动解释」的纯前端教学案例：用合成地震剖面演示断层概率体
预测（3D U-Net 语义分割）、断面骨架化与断层组合后处理三步核心。所有计算
都在浏览器里实时完成，不依赖任何后端。

怎么用
------
1. 直接双击打开 demo/index.html（整页模式，样式/脚本自动内联）。
2. 页面上三段实验 + 一段可选的「算法解剖」动画，控件都能拖。

文件清单
--------
case.json        站点元数据（专业背景 + 案例流程 + 示范引用）
demo/index.html  整页示范（算法解剖 + 3 个实验）
demo/demo.js     模型层 + 浏览器接线（断层概率/骨架化/分组）
demo/flow.js     算法解剖六阶段动画
demo/aflow.*     算法解剖引擎（公共）
demo/aiq.*       问答/评价组件（公共）
demo/demo.css    页面样式
_validate.js     模型层单测（node _validate.js）

示范内容
--------
屏 1  断层概率体：合成地震剖面 + 断层分割，拖「分割权重」看断层判别
屏 2  断面骨架化：阈值 + 细化，把断层概率提纯成断面中心线
屏 3  断层组合：连通域 + 剔碎段 + 走向分组 → 断层清单
算法解剖：数据接入 → 断层标签 → 概率体 → 类别不均衡 → 骨架化 → 组合

想改成你自己的案例
------------------
改 demo/demo.js 的 Model 层（genSeismic / faultProb / skeletonFault /
faultGroup），页面与动画会自动跟随新数据。需要换工区或真数据时，把
genSeismic 换成读取真实地震体的加载逻辑即可。
