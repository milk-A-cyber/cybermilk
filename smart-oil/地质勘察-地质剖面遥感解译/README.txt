地质剖面遥感解译 · 示范案例包
===============================

这是什么
--------
一个可以直接上传到「可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。
案例定位：地质勘察 · 地质剖面遥感解译，
用逐像素语义分割 + 构造线提取 + 矢量化后处理，
解决目视解译 1—2 周/幅、两人勾绘界线可差上百米的效率与一致性问题。

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（g1-remote-seg-case）整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景页，
   专业背景 / 案例流程 / 可运行示范三个 tab 立即出现。

示范内容
--------
【算法解剖】示范页最上方的核心板块：把「影像 → 矢量图层」拆成 6 步自动放慢播放——
  · 岩性栅格：合成影像（岩性体 + 噪声 + 断层带）；
  · 弱强标签：历史图件弱标签 vs 精修掩膜强标签；
  · 语义分割：U-Net 编码器-解码器逐像素预测类别；
  · 类别概率：概率图 + argmax → 岩性分布；
  · 构造线提取：梯度 + 阈值 → 线状构造要素；
  · 矢量化：连通域 + 剔碎斑 + 边界平滑 → 矢量图层。
  每一步跑的都是与实验 1—3 同一份真代码。

实验 1 · 语义分割
  切岩性类别数、拖分割权重，看预测结果与真值差距——
  为什么「逐像素判别岩性与构造」能替代人工勾绘。

实验 2 · 构造线提取
  拖构造线阈值，在「检出更多」与「噪声更少」之间取平衡——
  为什么构造线细长低对比、最易漏判。

实验 3 · 后处理矢量化
  调碎斑面积阈值，看连通域、剔碎斑、边界平滑——
  像素怎么变成可入库 GIS 的面要素。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和两块正文即可；
demo/ 文件夹换成你自己的页面或脚本也一样能传。
